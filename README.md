# Sistema de Gerenciamento de Playlist de Músicas

Projeto desenvolvido em C na disciplina de Estrutura de Dados, com o objetivo de aplicar conceitos de estruturas de dados dinâmicas e lógica de programação no desenvolvimento de um sistema de gerenciamento de playlists de músicas.

## Funcionalidades

- Adicionar músicas à playlist, incluindo inserção no início e no final.
- Inserir músicas em posições específicas da playlist.
- Remover e buscar músicas.
- Simular e movimentar músicas na playlist.
- Gerenciar o histórico de reprodução.
- Salvar e carregar playlists em arquivos.
- Salvar e restaurar o histórico de reprodução.

## Conceitos utilizados

- **Lista duplamente encadeada:** utilizada para organizar as músicas da playlist, permitindo operações de inserção, remoção e movimentação.
- **Pilha encadeada:** utilizada para armazenar o histórico de reprodução.
- **Alocação dinâmica de memória:** utilização de `malloc` e `free` para gerenciamento de memória.
- **Manipulação de arquivos:** persistência de dados por meio da gravação e leitura de arquivos.

## Tecnologias

- Linguagem C
- Estrutura de Dados
- Manipulação de arquivos
- Dev-C++
